# Security policy

Please do not report security vulnerabilities in public issues, pull requests or discussions.

## Reporting a vulnerability

Open the affected repository, go to the **Security** tab and choose **Report a vulnerability**. The report stays private between you and the maintainers.

Include what you can of:

- the affected repository and version or commit,
- the steps to reproduce,
- the impact you expect.

We acknowledge reports within five working days and keep you informed until the issue is resolved. Please give us a reasonable time to release a fix before disclosing it.

## Supported versions

Only the latest release of each repository receives security fixes.
