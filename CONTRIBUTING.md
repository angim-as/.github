# Contributing

Thank you for your interest in contributing.

## Issues

Search the existing issues first. If none matches, open a new one using the template and describe what you expected and what happened instead.

## Pull requests

1. Open an issue first for anything beyond a small fix, so the approach can be agreed before you write the code.
2. Keep each pull request focused on a single change.
3. Make sure the repository's checks pass.
4. Describe what the change does and why.

All pull requests are reviewed before they are merged. A pull request may be closed if it falls outside the project's scope.

## Conduct

By taking part you agree to follow the [code of conduct](CODE_OF_CONDUCT.md).
